## [Exploratory] Question 5: What Data Is Missing?

1. **Valuation / fundamentals**: P/E, EV/EBITDA, FCF yield, ROE, debt/equity, earnings-revision momentum (Compustat / FMP / Yahoo fundamentals). Price-only + macro misses mean-reversion to fair value.
2. **Market microstructure / sentiment**: short interest, put/call ratio, analyst revisions, news sentiment (FNSPID / GDELT), insider transactions. Useful for 30d horizon where positioning matters.
3. **Cross-asset regime**: VIX, HY spreads (ICE BofA), yield-curve slope (DGS10-DGS2), USD index (DXY), sector breadth. Current `DGS/FEDFUNDS/CPI/GDP` are level-only; spreads capture stress.
4. **International macro**: EU/India rates + CPI + FX (ECB, RBI FRED series) — universe is US/EU/INDIA but macro is US-only.
5. **Alternative**: add `VIX`, `DGS10-DGS2`, `BAMLH0A0HYM2 spread`, `DXY`, `country CPI/rates`, `short-interest % float`, `distance-to-52w-high`, all from FRED + yfinance, lagged to avoid leakage.
